# PROJECT: NIGHT

A small mobile-first 2D survival horror prototype.

## Run
Open `index.html` in a browser, or publish this repository with GitHub Pages.

## Controls
- Drag the on-screen joystick to move.
- Tap the flashlight button to toggle the flashlight.
- Collect 3 fuses and reach the exit.
- Avoid the creature.

## Files
- `index.html` — game page
- `style.css` — mobile interface
- `game.js` — game logic
- `manifest.json` — basic PWA settings

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
