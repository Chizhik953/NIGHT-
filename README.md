# PROJECT: NIGHT — Последняя смена

Пиксельный 2D-хоррор на выживание.

## Сюжет

2039 год. Алекс начинает ночную смену в заброшенном исследовательском комплексе «Ночной-13».

Внутри здания находится нечто, что не должно было проснуться.

## Особенности

- Пиксельная графика
- Три локации
- Шесть предохранителей
- Батарейки и ключ-карта
- Фонарик с направленным лучом
- Монстр-тень с красными глазами
- Сюжетные события и диалоги
- Управление для iPhone

## Управление

- Джойстик — движение
- Кнопка ☼ — фонарик
- Касание двери — переход в следующую локацию

## Технологии

HTML, CSS, JavaScript, Canvas.
